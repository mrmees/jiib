## Deferred findings

- **WR-01 — `maxItems` pool-size axis is dead.** Fully plumbed (persist → sanitize → resolve →
  round-trip) but has NO live write surface and NO UI: `setMaxItems` is test-only, the editor
  hardcodes `take(4)`. Decide: wire a UI control for pool size, or delete the dead plumbing.
- **WR-02 — color wheel captures HUE only.** `Color.hsv(hue, 1f, 1f)` discards saturation/value
  on both write and re-open, so a user cannot pick a muted or dark status/pool color — quietly
  undercuts the D-03 "the color is yours" promise. Decide: add S/V control (2D picker or
  sliders) or document the hue-only constraint as intentional.
- **WR-03 / WR-05 — editor handle-vs-render consistency edges** around the status picker
  (`effectiveStatusColor` is mode-blind; the swatch can preview an override color in a mode
  that ignores it). Reconcile what the swatch shows vs what the active palette mode renders.
- **Info items (6):** stale `OPAQUE_BLACK` KDoc (comment is wrong about what the constant does),
  0..359-vs-0..360 hue doc/test drift, `fmt()` duplicated across 4 files (extract a shared
  helper), Reset-confirm copy grammar bug, etc.
