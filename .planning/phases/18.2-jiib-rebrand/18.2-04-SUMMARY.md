# Phase 18.2 Plan 04: jiib In-App Brand Surfaces Summary

Applied the jiib brand to the two strongest in-app moments — the Splash front door (stacked
icon+wordmark lockup) and the About APP block (wordmark + jib-explainer note) — both accent-tinted
through a new `brandTint` helper that resolves the D-06 accent-vs-bg contrast watch-item with a
tested contrast-floor fallback, plus a six-theme preview matrix that exposes that contrast risk
before device.

## What Was Built

### Task 1 — `brandTint` contrast-floor helper + host test (`9907689`)
`theme/BrandTint.kt`: a PURE top-level `brandTint(accent, bg, text): Color`. Computes the WCAG-style
relative-luminance contrast ratio `(Lmax + 0.05) / (Lmin + 0.05)` (L via the Compose `Color.luminance()`
extension already used in `ThemeEditorScreen`); returns `accent` when the ratio clears the named
`BRAND_CONTRAST_FLOOR = 3.0f` (the W3C 1.4.11 large-graphic non-text minimum, cited in KDoc), else the
always-legible `text` token. No Composable, no token dependency beyond the three `Color` args — so it is
host-unit testable and reusable by both Splash and About. `BrandTintTest.kt` (JUnit, host — `Color` is a
value class) asserts high-contrast accent-on-navy returns the accent, a near-bg accent returns text, the
floor equals 3.0f, and the white-on-black / accent==bg boundaries. **`:app:testDebugUnitTest --tests
*BrandTintTest` → BUILD SUCCESSFUL, GREEN.**

### Task 2 — Splash jiib lockup replaces the brand Text (`58e5d41`)
`SplashScreen.kt`: the `"Dinghy Display"` brand `Text` is replaced by a call to a new stateless
`internal fun SplashBrandLockup()` that reads ONLY `LocalTokens.current` (NO AppContainer — the preview
seam). It renders `Icon(painterResource(R.drawable.jiib_lockup))`, `contentDescription =
stringResource(R.string.cd_jiib_logo)`, `tint = brandTint(t.accent, t.bg, t.text)` (D-04 lockup, D-06
guard), sized by ratio (`fillMaxWidth(0.6f).wrapContentHeight()` — no magic px, LAYOUT.md). The reason
`Text` and the recovery `Row` are unchanged (D-04). Dropped the now-unused `Geist` import (the reason
Text uses `GeistMono`). Zero `"Dinghy Display"` literal remains.

### Task 3 — About wordmark + tagline/jib-note + brand preview matrix (`1a5b8dd`)
`AboutScreen.kt`: the `SectionLabel("Dinghy Display")` is replaced by a stateless `internal fun
AboutWordmark()` (AppContainer-free, reads only `LocalTokens`) rendering `Icon(painterResource(
R.drawable.jiib_wordmark))` tinted `brandTint(...)` (D-05 wordmark-only, D-06), ratio-sized
`fillMaxWidth(0.55f)`. The hardcoded tagline becomes `stringResource(R.string.about_tagline)` (D-10),
and the D-11 jib note (`stringResource(R.string.about_jib_note)`) renders directly below it, mirroring
the tagline treatment (`t.text3` / `Geist` / `fsSp(15f)` — the 15sp metadata floor). The `SectionLabel`
helper is retained (the Developer label still uses it). Zero `"Dinghy Display"` literal remains.

`preview/BrandPreviews.kt`: follows the `FineTunePreviews` shape — `@Nexus7Previews` composables driving
the stateless `SplashBrandLockup()` AND `AboutWordmark()` seams (NOT the screen entry points, NOT any
AppContainer) across all six `themeCombos` seeds via `PreviewBox(seed){...}`, plus an `fs = L` overflow
shot. The six-combo matrix is what surfaces the D-06 accent-vs-bg contrast risk visually before device.

## Deviations from Plan

**1. [Rule 3 - Blocking] Brand seams made `internal` instead of `private`**
- **Found during:** Task 3 (creating BrandPreviews.kt).
- **Issue:** The plan specified `SplashBrandLockup()` / `AboutWordmark()` as `private`, but BrandPreviews
  lives in the separate `works.mees.dinghy.preview` package and cannot reference a `private` member —
  the preview file would not compile.
- **Fix:** Changed both seams to `internal` visibility. They remain stateless and AppContainer-free
  (the actual preview-safety requirement of D-03 / Codex finding 04 is unaffected); `internal` is the
  minimal visibility that lets the same-module preview package drive them.
- **Files modified:** SplashScreen.kt, AboutScreen.kt.
- **Commits:** 58e5d41 (Splash), 1a5b8dd (About).
