<objective>
Two independent, dependency-free foundation pieces: (1) bundle the Geist / Geist Mono static-weight TTFs
in `res/font/` and expose them as Compose `FontFamily`s (D-04, Pattern 2 — static weights only, API-23
floor); (2) the plain-Kotlin bounded `RingBuffer` holder (D-12) that the render primitives consume — a
unit-testable rolling window fed by the throttled `StateFlow`, surviving View recreation/rotation/theme
swap. Neither depends on the resolver, so this runs in parallel with 03-01.

Purpose: Variable Geist fonts silently collapse to one weight on API<26 (RESEARCH Pitfall 2); static
weights are mandatory. The ring buffer is the toolkit-agnostic data substrate both render primitives draw.
Output: bundled fonts + FontFamily + the bounded buffer + its unit test.
</objective>
