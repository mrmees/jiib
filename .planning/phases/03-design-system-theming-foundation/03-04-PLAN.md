Pure Compose UI primitives + a one-method interface. No trust boundary crossed: no sockets, no
persistence, no untrusted input. The ConfirmGuard is a SAFETY affordance (gates destructive actions) but
dispatches nothing itself — PRIM-05 command-dispatch is Phase 4.

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-04 | Tampering | ConfirmGuard as a destructive-action gate | mitigate | The guard requires an explicit confirm callback before the (later) destructive call fires; destructive=red intent is visually distinct from positive=green (PRIM-03), reducing mis-tap risk. No command is dispatched in this phase. |

Note: LOCAL-ONLY UI substrate. No HIGH-severity threats; no network/auth threats applicable.
