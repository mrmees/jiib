# Phase 3 — Design System & Theming Foundation

Created by the 2026-05-31 scope restructure. This phase builds the reusable UI substrate
(semantic-token theming dark/light/custom + S/M/L text size, the Focus/Field/Gutter responsive
grammar for portrait + landscape, the outline-led control language, and the core components:
Confirm guard, single-setting scrubber/stepper page, severity toast, progress-ring + line-graph
render primitives) that every later screen inherits.

**The UI design contract is `docs/ui_design/` (LAW)** — there is NO generated UI-SPEC for this phase;
the design bundle IS the spec. See the repo-root `CLAUDE.md` § "UI Design System".

**Requirements:** THEME-01, THEME-02, UI-01, UI-02, PRIM-01, PRIM-03, PRIM-04 (see `.planning/REQUIREMENTS.md`).
