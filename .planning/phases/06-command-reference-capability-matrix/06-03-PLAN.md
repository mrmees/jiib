| Session handshake -> printer state | Registry-backed requests seed the live state store. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-06-03-D | Denial of Service | gcode.script migration | mitigate | Keep dispatcher timeout tests green; no direct bypass around finite timeout/in-flight removal. |
| T-06-03-I | Information Disclosure | service failures | mitigate | Preserve dispatcher redaction tests and avoid propagating transport exception messages into UI copy. |
