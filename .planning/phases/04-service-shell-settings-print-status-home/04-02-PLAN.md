<objective>
Build the two pure, host-testable primitives the whole shell codes against: the shared
command-dispatch wrapper (PRIM-05, D-18) and the top-level route derivation (D-05/D-06).
Both are toolkit-agnostic (no Compose), so they are proven under `runTest` virtual time before
any UI consumes them — the screens in Wave 3 and the integration in Wave 4 depend on these.

Purpose: Every Moonraker action call gets an explicit timeout, an in-flight/busy state, and tap
debounce (no infinite hang, no double-fire); routing is keyed off Klippy/print lifecycle, never
socket state, so a transient reconnect can't bounce the user off the home screen.
Output: `CommandDispatcher`, action method strings in `JsonRpc.kt`, pure `derive()` in `TopRoute.kt`,
and two host-side tests.
</objective>

| T-04-02-R | Repudiation/double-fire | CommandDispatcher | mitigate | debounce window + in-flight Set guarantee a destructive action (estop) fires at most once per intentional tap — a stray double-tap cannot re-issue it |
