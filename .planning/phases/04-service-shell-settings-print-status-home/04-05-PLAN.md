<objective>
Build the splash/initializing surface (SHELL-05) — a **hard override** with no reachable App Drawer
(D-06), so EVERY escape hatch must live on the splash itself or the user is trapped. It covers the
three trapped states: first-run/no-config (D-11 → Settings), Klippy shutdown/error with Moonraker
reachable (D-12 → Retry + firmware_restart + restart), and a saved-but-failing connection (D-13 →
Retry + Edit connection). This is the recovery surface the E-stop (04-06) lands on when it drives
`klippy_state → shutdown`.

Purpose: A printer that's starting up, shut down, or unreachable never leaves the user stranded — the
exact recovery action is always one tap away on the screen they're stuck on.
Output: `ui/screen/SplashScreen.kt`.
</objective>
