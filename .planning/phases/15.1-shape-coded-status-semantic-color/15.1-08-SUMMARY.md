# Phase 15.1 Plan 08: THEMING.md canonical token-law rewrite Summary

Rewrote `docs/ui_design/THEMING.md` as the canonical in-repo token-law (D-13) absorbing the full
as-built 15.1 model — status-by-shape, pure-neutral surfaces, the data pool, the N-series rule,
accent-led directional, palette modes, the OKLCH bed-mesh sub-system, neutral Back — verified
field-by-field against the committed theme code; and reconciled `docs/ui_design/CLAUDE.md` so Back is
no longer red (D-10) and heat is the caution color (D-13).

## What was built

**Task 1 — THEMING.md rewrite (`d1c2ce8`):** Replaced the partially-superseded 119-line doc with a
canonical token-law that:
- Reframes "How themes are applied" from CSS-attribute-flips to the actual **Kotlin generate-and-cache
  pipeline** (seed → `Palette` → `TokenBridge` → `BakedTokens` (sRGB, because OKLCH renders wrong on
  API < 26) → `ThemeResolver` → immutable `ThemeTokens`).
- Documents `--heat` / `ThemeTokens.heat` as the **CAUTION** color, not heater-amber (D-13), with
  temperature identity carried by `directional.temperature` (= accent) + the pool. Surfaces are
  **pure-neutral** (D-16).
- Adds the **Status Shape Vocabulary** (D-01/D-02): octagon = stop, triangle = caution, **go is
  shapeless** (color-only, no circle in dinghy); coverage = safety-critical only; the icon COLOR carries
  state while a control OUTLINE may carry a separate axis (Move's directional group color), and lock
  open/closed is the force-move silhouette (D-12).
- Adds the **N-series rule** table (D-05): accent-led in all 3 modes, Colorful = accent+pool wrapping
  infinitely (never status colors), Simple = accent/text, High-Contrast = stoplight cycle; no
  user-facing cap (D-09); negative index throws.
- Adds **accent-led directional** (D-06/D-07): temperature = accent, xy = pool[0], z = pool[1]; bed/
  chamber dual-tag; flagged as superseding the Phase-15 wiring AND the sibling spec (owner override).
- Adds **Palette modes** (D-04): fixed RYG is the High-Contrast escape hatch ONLY (force-overrides user
  overrides), NOT the default doctrine.
- Adds the **bed-mesh OKLCH sequential sub-system** (D-11): blue→teal→yellow, off pure red/green, baked
  once, golden-locked — its own thing, not the categorical pool.
- **Back = NEUTRAL/outline** (D-10) with the consistent-gutter-position rule, and an **honest deferral
  note** that 15.1 applied it on Move only / the app-wide sweep is a Phase-15.2 todo.
- Preserves the **PromptMarkup author-hex carve-out** and the outline-rule verbatim; **points to**
  `../theme_theory/COLOR-SYSTEM.md` for deep rationale without vendoring it.

**Task 2 — CLAUDE.md reconciliation (`cb417b8`):** The button-intent grammar no longer puts Back on
green/red (now "accept, done, commit" for green; "white/neutral = setting + plain navigation"); added a
dedicated **Back = NEUTRAL/outline (D-10)** bullet with the position rule + the 15.2 deferral + a pointer
to THEMING.md. Also fixed the "Hi-fi visual language" residue: heat = caution (D-13), surfaces
pure-neutral (D-16), shape carries safety, and dropped "status dot breathes" (no continuous animation).
