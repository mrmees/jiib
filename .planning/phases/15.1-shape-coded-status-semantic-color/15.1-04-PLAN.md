<objective>
Extend the existing per-profile durable override path to the 3 status slots (D-03), MODE-GATED per D-04:
in Colorful the user's `stop`/`caution`/`go` overrides apply; in Simple status collapses to text
(overrides ignored); in High-Contrast status is force-set to the fixed RYG safety palette regardless of
any stored override. Persisted per-profile, fail-safe-sanitized, applied in `TokenBridge`. Reuses the
Phase-14/15 `writeScope` + `mutateActive` path and the existing per-entry sanitizer — no new persistence
path, no new sanitizer.

Purpose: Safety is carried 100% by shape + icon + position (Area A), so status colors are freely
editable IN COLORFUL — but Simple/High-Contrast mode semantics MUST NOT be defeated by a stored override
(the one genuine correctness gap from review). This wires the persistence + mode-gated application; plan
07 wires the editor UI.
Output: mode-gated status-override persistence + application + fail-safe, with GREEN per-mode unit tests.
</objective>
