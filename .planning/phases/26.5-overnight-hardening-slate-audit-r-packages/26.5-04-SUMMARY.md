# Phase 26.5 Plan 04: R1 Install & Display Correctness (code-only) Summary

Both-ABI release splits with collision-free per-ABI versionCodes, edge-to-edge chrome with safeDrawingPadding insets, predictive-back manifest opt-in, and a one-shot POST_NOTIFICATIONS request at first connect — roadmap §R1 steps 1-4, code half only.

## What Was Built

**Task 1 — ABI splits + per-ABI versionCode (`be72f29`):**
- `splits.abi.include("armeabi-v7a", "arm64-v8a")`, `isUniversalApk = false` retained.
- `versionCode` hoisted to a single top-level `val appVersionCode = 1`; `defaultConfig` reads it.
- New top-level `androidComponents { onVariants { ... } }` block reads each output's ABI filter via `FilterConfiguration.FilterType.ABI` and sets `output.versionCode.set(appVersionCode + offset)` (v7a=0, arm64=+1) — the Property API per the plan's CODEX HIGH annotation; no legacy `applicationVariants.all`.
- D-01a comment rewritten: Nexus 7 2013 = dev-floor that installs the v7a APK; ship artifacts publish BOTH per-ABI APKs. The "can never carry an arm64 slice" claim is gone.
- Plan 26.5-01's lint/toolchain edits and 26.5-03's testOptions block untouched (diff scoped to splits/versionCode/onVariants/comment).

**Task 2 — edge-to-edge, predictive back, notifications, R2 pre-stage (`34ea1ff`):**
- `enableEdgeToEdge()` is the FIRST statement of `onCreate`, before `super.onCreate` (Pitfall 1).
- Root Box modifier chain: `.fillMaxSize().background(t.bg).safeDrawingPadding()` — background paints edge-to-edge behind status/nav/cutout; content stays chrome-clear. The four Views-hosted surfaces (Files/Console/Graph/Webcam) live inside this root and inherit.
- Manifest `<application android:enableOnBackInvokedCallback="true">` — required at targetSdk 35, silently ignored API 23-32.
- `notificationPermLauncher` registered as an Activity FIELD via `registerForActivityResult(ActivityResultContracts.RequestPermission())` with a documented no-op handler. Trigger: `LaunchedEffect(Unit)` suspends on `container.connectionState.first { it is ConnectionState.Connected }` then calls `requestNotificationPermissionIfNeeded()` — gated by `Build.VERSION_CODES.TIRAMISU`, `ContextCompat.checkSelfPermission`, and a once-per-process field latch.
- `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` declared next to the existing permissions, commented as R2's pre-staged declaration (wave-3 manifest ownership; plan 26.5-05 consumes it).

**Task 3 — build gate (no files):**

- `app/build/outputs/apk/release/` contains exactly `app-armeabi-v7a-release-unsigned.apk` and `app-arm64-v8a-release-unsigned.apk`, zero universal APKs.
- `output-metadata.json` confirms versionCode 1 (v7a) / 2 (arm64) and `minSdkVersionForDexing: 23`.
- `git status --porcelain` clean after final task commit.
