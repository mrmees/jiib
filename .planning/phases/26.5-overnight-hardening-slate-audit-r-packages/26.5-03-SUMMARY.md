4. **Swipe-up accumulation (Part 5 cause #3)** — `SwipeUpAccumulator` (pure Kotlin, zero Compose imports): accumulates per-gesture, fires once at ≤ −80f, latches until `onDragStart`. Both behind `BuildConfig.DEBUG`; release path provably zero-cost (guard + R8).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Host tests would crash on the new debug logging**
- **Found during:** Task 1 (pre-implementation analysis)
- **Issue:** `android.util.Log.d` at the dispatcher's early returns runs during `testDebugUnitTest` (`BuildConfig.DEBUG = true`, and the busy/debounce tests exercise those exact paths); without mock config the JVM android.jar throws "not mocked", failing the suite.
- **Fix:** `testOptions { unitTests.isReturnDefaultValues = true }` in app/build.gradle.kts — Log no-ops in host tests.
- **Files modified:** app/build.gradle.kts
- **Commit:** `bb19217`

**2. [Rule 1 - Bug] Temperature's local WR-01 pre-check defeated the heater rejection flash**
- **Found during:** Task 1 (wiring TemperatureScreen)
- **Issue:** `onNudgeHeater`'s `if ("set_heater_$name" !in inFlight)` pre-check dropped busy re-taps locally — BEFORE the dispatcher — so the new `rejectedKey` feedback could never fire for the heater stepper's in-flight case (exactly the silent swallow R10 exists to kill). The check also compared a composition-stale `inFlight` snapshot.
- **Fix:** Removed the redundant local pre-check; the dispatcher's atomic in-flight guard performs the identical same-key drop AND emits feedback. Printer-protection semantics unchanged (the dispatcher guard is a strict superset). The now-unused `inFlight` collection in the live overload removed with it.
- **Files modified:** app/src/main/java/works/mees/dinghy/ui/temperature/TemperatureScreen.kt
- **Commit:** `bb19217`

## Report Notes

**Debug instrumentation — how to use it in the morning session:**
- **Flag:** everything is gated on `BuildConfig.DEBUG` — there is no separate toggle. Install a **debug build** (`:app:assembleDebug` / `installDebug`) and the instrumentation is live; release builds carry zero cost. Force-rebuild and check the APK mtime before installing ([[dinghy-stale-apk-uat-gate]]).
- **Logcat tags:**
  - `Dispatcher` — one line per intentionally-dropped tap: `reject: key=<dispatchKey> reason=in_flight` or `reason=debounce remaining=<ms>ms`. Counting these against "missed" taps answers how many misses were intentional rejections (Part 5 recipe 2).
  - `SwipeDetector` — one line per drag event: `drag: amt=<delta> total=<runningTotal> fired=<bool>`. Watch the running total approach −80 on slow swipes (Part 5 recipe 3).
  - Filter: `adb logcat -s Dispatcher SwipeDetector`
