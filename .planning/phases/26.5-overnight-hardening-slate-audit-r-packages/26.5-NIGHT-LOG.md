## Resiliency (owner request 2026-06-11 ~00:00: survive 5-hour usage-window exceedance)

- **OS watchdog:** `night-watchdog.sh` (this dir) runs detached (`pgrep -f night-watchdog.sh`),
  log `/tmp/dinghy-night-watchdog.log`. Every 15 min: if NIGHT-LOG lacks the line-anchored
  completion sentinel (see top note) AND the
  branch's last commit is >45 min old → relaunches `claude -p "<resume per NIGHT-LOG>"
  --dangerously-skip-permissions` (retry-throttled 90 min; if the usage window is still exhausted
  the relaunch fails fast and retries next cycle). Hard-stops at 09:30 CT. Kill:
  `pkill -f night-watchdog.sh`.
- **In-session heartbeat:** session-only cron `434a5e16` (hourly :23) — dies with the session;
  the OS watchdog is the real safety net. A resumed session should NOT recreate it.
- **Liveness contract for executors:** commit at task boundaries (GSD default) so the watchdog's
  staleness signal stays fresh. If a single legitimate step will exceed 45 min without a commit
  (possible — plan 03's longest task gap was ~20 min), touch a `docs(26.5): night-log heartbeat`
  commit on the ledger.
