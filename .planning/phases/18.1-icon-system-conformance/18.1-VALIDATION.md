## Sampling Rate

- **After every task commit:** `:app:testDebugUnitTest --tests *DinghyIconsTest` + `python tools/verify_ligatures.py`
- **After every plan wave / before any drawable deletion:** `:app:assembleDebug` (compiler completeness for deletions)
- **Before `/gsd-verify-work`:** full unit suite green + on-device spot check
- **Max feedback latency:** ligature script + targeted unit test = seconds; full build minutes
