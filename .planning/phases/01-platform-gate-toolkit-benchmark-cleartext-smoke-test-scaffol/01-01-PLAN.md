<objective>
Stand up the pinned, multi-module Android build scaffold that compiles, assembles a 32-bit
release APK, and self-enforces the minSdk-23 floor. This is the PKG-02 deliverable, and it is
the SINGLE OWNER of the shared `AndroidManifest.xml` + network-security-config so the Wave-2
plans never edit those shared files (preventing same-wave file conflicts).

Purpose: The whole project's risk profile is "a modern AndroidX/Compose lib silently drops
API 23." Pinning the catalog is necessary but NOT sufficient — the delivered control is a
`verifyMinSdk` Gradle task on the MERGED manifest (per RESEARCH #5). This plan delivers both
the pinned floor and the enforcement that proves it, plus the cleartext manifest posture
(RESEARCH #6 / D-10) that the Wave-2 smoke test and benchmark both depend on.

Output: `settings.gradle.kts`, root + `:app` + `:macrobenchmark` build files, a pinned
`gradle/libs.versions.toml`, the `verifyMinSdk` convention/script plugin, the shared manifest +
NSC, a minimal `MainActivity`, a `BenchActivity` skeleton, and a release `armeabi-v7a` APK.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dependency supply chain → build | Transitive AndroidX/Compose deps can silently raise minSdk or pull unintended ABIs/code |
| dev box → release artifact | The signed release APK is the shipped surface; build config governs what ships |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | merged manifest minSdk | mitigate | `verifyMinSdk` task fails the build if merged minSdk != 23 (PKG-02 control) |
| T-01-02 | Elevation/Compat | transitive dependency minSdk creep | mitigate | pinned version catalog + adversarial verifyMinSdk test proving a minSdk>23 dep fails |
| T-01-03 | Tampering | release ABI set | mitigate | abiFilter restricts release APK to armeabi-v7a only (asserted via unzip lib/ check) |
| T-01-04 | Information Disclosure | cleartext posture set in shared manifest/NSC | accept | Trusted-LAN scoped decision (CONN-05); the only Moonraker surface, printer + tablet share the LAN — documented as a decision, not an oversight |
| T-01-SC | Tampering | gradle/maven dependency installs | mitigate | every version pinned in catalog; no dynamic (`+`) versions; all first-party group IDs per RESEARCH Package Legitimacy Audit |
</threat_model>
