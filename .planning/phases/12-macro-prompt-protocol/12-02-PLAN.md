## Trust Boundaries

|----------|-------------|
| Macro-authored event stream -> reducer state | Untrusted ordered events (begin/show/content/end/disconnect, possibly malformed ordering) drive the state machine; must degrade deterministically, never wedge |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05 | DoS (wedge) | `reduce` state machine | mitigate | Pure total function over a sealed event set; malformed ordering (show-before-begin, stray-row-end, nested container, content-before-begin, repeated show) degrades deterministically per the JS reference and is proven by the 26 fixtures + 8 hardening cases. A garbage stream cannot leave a stuck/leaked prompt (PROMPT-03 never-wedge). |
| T-12-06 | Tampering (cross-state leak) | `begin` / pending consumption | mitigate | pendingTargets/pendingSize are consumed (reset to null) even on a Suppressed begin, so a suppressed prompt's metadata never leaks into a later prompt (size-consumed-when-target-suppressed fixture). epoch bumps on begin so a replace-active-prompt starts clean. |
| T-12-07 | Information Disclosure (state leak) | `promptView` projection | mitigate | The view exposes EXACTLY 6 keys; internal fields (lifecycle/epoch/pending*/activeContainer/opts) never leak to the render layer (exact-6-keys structural assertion). |
| T-12-08 | (no high threats) | — | accept | No I/O, no auth, no network — pure host logic. |
