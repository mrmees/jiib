<objective>
Build the two layout primitives every redesign screen depends on — the unit-grid `U` derivation and
the edge-faded list wrapper — and turn the UnitGridTest RED scaffold GREEN.

is an integer number of units, derived from the LANDSCAPE content height (5U phone-land floor → 7U

grammar uses everywhere. These two primitives have no dependency on the components in 23-05 (the kit
build), so they ship first and unblock it. The pure formula must be host-testable (no Compose) so the
RED scaffold from 23-01 turns GREEN.

Output: `UnitGrid.kt` (data class + `rememberUnitGrid()` + pure helper), `ListBlock.kt`, GREEN
UnitGridTest, and a @Preview demonstrating the grid.
