<objective>
Build the PURE state layer: the `PrinterStateReducer` (snapshot-seed + diff-merge, STATE-01), the
`deriveCapabilities` function plus a pure `deriveSubscribeSet` helper (STATE-02 / A3), and the
Klippy-lifecycle exposure (STATE-04) — all I/O-free, coroutine-free, and unit-tested over the Wave-0
golden + fallback corpus.

Purpose: This is the riskiest correctness surface in the phase (RESEARCH: "the risk is getting the
diff-merge and id-correlation semantics exactly right"). Keeping it pure means it is trivially and
deterministically testable with no socket — the golden frames prove merge semantics, capability gating,
and lifecycle transitions in isolation. Capability derivation is pure precisely so the Wave-3 handshake can
re-run it on EVERY reconnect (STATE-02). The `deriveSubscribeSet` helper supplies the handshake the exact
`objects.subscribe` set to request (v1 superset intersected with the detected `objects.list`, A3), which is
what lets 02-04 sequence `objects.list → deriveCapabilities → objects.query → objects.subscribe` correctly.
The Wave-3 session plan wires these into the live StateFlow.

Output: `state/PrinterStateReducer.kt`, `state/DeriveCapabilities.kt` (with `deriveCapabilities` +
`deriveSubscribeSet`), and three JVM unit tests (`PrinterStateReducerTest`, `DeriveCapabilitiesTest`,
`KlippyLifecycleTest`) all green over the golden + adversarial + fallback fixtures from Plan 01.
</objective>
