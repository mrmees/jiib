<objective>
Build the transport + protocol seams: `MoonrakerSocket` (OkHttp `WebSocket` → `callbackFlow` raw-frame
bridge with an injectable socket factory), a concrete `RpcConnection`/`ActiveSocket` abstraction whose
lifecycle is bound to the live socket (created after `onOpen`, invalidated on close), and `JsonRpcClient`
(the `Map<id, CompletableDeferred>` correlation layer with per-request timeouts + atomic close-cleanup +
notification routing by method) — the STATE-05 correctness surface plus the pending-RPC-lifecycle and
socket-ownership fixes from the review.

Purpose: STATE-05 ("response matched by id, never by arrival order, under interleaved notify_*") is a
named success criterion and a first-class adversarial-tested seam. Isolating socket and protocol from the
session lets the interleaving proof run against the `FakeWebSocket` with zero reconnect/handshake noise.
The injectable factory is the testability seam the whole phase leans on. This pass adds two review HIGH
fixes at this layer: (a) a concrete `RpcConnection` so it is IMPOSSIBLE to send before open or after close
(replacing the loose "cold callbackFlow + separate send()" shape), and (b) per-request timeouts plus
`JsonRpcClient.close(cause)` that atomically fails+clears all pending deferreds on socket death / send
failure / parse failure — so the handshake and reconnect supervisor (02-04) can never deadlock on a
deferred that will never resolve.

Output: `net/MoonrakerSocket.kt`, `net/RpcConnection.kt`, `net/JsonRpcClient.kt`, and three JVM unit tests
(`JsonRpcClientTest` proving id-correlation under interleaving + notify routing + gcode-stream separation +
close-fails-all-pending + per-request timeout; `RpcConnectionTest` proving send-before-open and
send-after-close fail cleanly; `MoonrakerSocketTest` proving the callbackFlow bridge + cancellation via the
FakeWebSocket) — all green.
</objective>
