<objective>
The P0-mandatory compile-cascade foundation (D-02): annotate the entire `PrinterState` tree `@Immutable` and migrate every `Map`/`List` field to `ImmutableMap`/`ImmutableList`, then update BOTH the `PrinterStateReducer` (the dominant construction site) AND the `PrinterStateStore` emission boundary to produce those immutable types. This is the single highest-impact fix — `PrinterState` is emitted at 4 Hz and is currently unstable, so today Compose cannot skip ANY composable that reads it.

Purpose: D-02 P0 root-cause fix for wide recomposition; the field-type changes here cascade to consumer call sites in later waves (which is why this lands before the split + push-down).
Output: An `@Immutable` `PrinterState` tree with immutable collection fields and a reducer + store that emit them.

Type decision is explicit (ImmutableMap/ImmutableList declared; `.toImmutableMap()`/`.toImmutableList()` at the assignment boundary; PersistentMap/PersistentList only where in-place persistent mutation is used — currently nowhere). Targeted reducer tests added for the four conversion-sensitive paths. Adjacent `Capabilities` List fields audited.
