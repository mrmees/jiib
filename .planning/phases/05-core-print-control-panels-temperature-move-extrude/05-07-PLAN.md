<objective>
Build the Extrude panel (EXTR-01..04) — Move-style (no mockup, D-08): follow the Move template within
Focus/Field/Gutter. Mirror the Phase-4 holder+screen+dispatch patterns.

Layout (D-08): Extrude / Retract as primary actions + a 6-up distance selector + a speed selector.
Keyboard-free (selectors / scrubber pages; no keypad). Tool selector shown only on multi-extruder.

Behaviors:
- EXTR-01: Extrude → `PrinterCommands.extrude(+dist, speed)`; Retract → `extrude(-dist, speed)`
  (SAVE/M83/G1 E±/RESTORE). Distance + speed via selector buttons.
- EXTR-02/D-10: Load/Unload ALWAYS shown; if `capabilities.hasMacroIgnoreCase("LOAD_FILAMENT")` is
  false, tapping shows an informational SeverityToast ("No LOAD_FILAMENT macro configured"); when true,
  dispatch `loadFilament()` / `unloadFilament()`.
- EXTR-03/D-09: a T0/T1… tool selector shown ONLY when `capabilities.extruderCount > 1`; selecting
  dispatches `selectTool(n)`. Hidden entirely on single-extruder printers.
- EXTR-04/D-07: gate Extrude/Retract on the LIVE `can_extrude` boolean of the active extruder. While
  false, controls are visibly disabled (reduced opacity) with an inline reason "Heat nozzle to
  extrude" — append the real `min_extrude_temp` (from the spine, 05-03) when available, e.g. "Heat
  nozzle to 170°C to extrude". No failed taps.

Purpose: prove the live-capability safety gate (cold-extrude) + the missing-macro popup pattern.
Output: ExtrudeHolder + ExtrudeScreen, with a holder unit test.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07-Safety | Safety | cold extrusion damaging the hotend/extruder | mitigate | Extrude/Retract gated on the LIVE `can_extrude` boolean (EXTR-04/D-07), default fail-safe false; disabled-and-explained, no failed taps; Klipper firmware also rejects below min_extrude_temp as a backstop. |
| T-05-07-T | Tampering | double-tap re-issues an extrude / tool switch | mitigate | All taps via CommandDispatcher (debounce + in-flight); controls disabled off `inFlight`. |
| T-05-07-T2 | Tampering | extrude distance/speed built from selectors | mitigate | Distance/speed are FIXED sets; `PrinterCommands.extrude`/`selectTool` clamp numerics (05-02) — no free-text. |
| T-05-07-D | DoS | hung extrude/load wedging a control | mitigate | Dispatcher timeout clears the in-flight key in `finally`. |
