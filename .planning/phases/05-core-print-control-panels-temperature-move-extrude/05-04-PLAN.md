<objective>
EXTEND the single-trace `GraphView` in place to N traces with a fixed shared Y-range — the only
genuinely new render work in the phase (D-05) and the architectural fix for Phase-4 gap G-1. Do NOT
fork it (CONTEXT D-05 / RESEARCH anti-pattern): the allocation-free contract and the perf gate stay
anchored to the ONE primitive.

Work (PATTERNS "render/GraphView.kt MODIFY", RESEARCH Pattern 3 / Pitfall 4):
- Generalize the single `linePath`/`linePaint` to `Array<Path>`/`Array<Paint>`, one per drawn sensor,
  pre-allocated; keep `rewind()`-per-draw, never allocate in `onDraw`.
- Replace the per-frame window min/max Y auto-range (current lines 116-125) with a FIXED shared
  Y-range defaulting to `0f..350f` °C (covers the setHeater 0..350 clamp ceiling — a 0..300 default
  would clip a legal nozzle target; Codex finding) so steady temps no longer noise-fill the panel
  (G-1 fix). One shared X time window across traces.
- Add an optional DASHED horizontal setpoint line per trace (D-04): accept `setpoints: List<Float?>`
  (one per trace; null = no line). Pre-allocate ONE dashed `Paint` (DashPathEffect built ONCE in init,
  never in onDraw); for each trace with a non-null setpoint, draw a horizontal line at that setpoint's
  y-mapped position in the trace's color. Current-setpoint line only — not the historical target series
  (deliberate fill-budget narrowing).
- `applyTokens` sets each trace's color from tokens: nozzle=`t.heat`, bed=`t.accent`, chamber=`t.violet`
  (added 05-02). No raw hex (THEME-01). Per Pitfall 4, draw the area-fill for the primary trace only
  (or none) to bound fill cost on the Adreno 320 — but this is a perf lever, MEASURE in 05-08.
- `GraphViewHost` widens to accept N per-sensor snapshots + the token colors and pushes them into the
  same instance (`factory` once); a theme flip recolors all traces with no recreation.

Keep the existing single-trace entry path working (Print Status sparkline still calls it).

Purpose: the multi-trace history graph the Temperature panel (05-05) hosts, with the G-1 fixed-range fix.
Output: N-trace GraphView + multi-snapshot host, with extended downsample/sanitize tests.
</objective>
