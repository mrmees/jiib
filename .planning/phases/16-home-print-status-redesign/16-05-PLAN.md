<objective>
Persist the babystep app setting (D-06) and add the forward-stub drawer tiles (D-02). The babystep
setting — enable toggle (default ENABLED) + positive-integer layer-count (default 5) — lives under the
Settings tile of the Phase-15.2 four-tile IA, persisted via a NEW `babystep.preferences_pb` DataStore

theme/connection/macros/webcam/profiles) and threaded into `AppContainer`, then written through
`AppContainer.writeScope` intent helpers (NEVER `rememberCoroutineScope()` — the project's #1 recurring
trap, 4+ device strikes). Greyed "Output" (P18) and "System Info" (P19) stubs go in the App Drawer only.

Purpose: the Wave-3 babystep row reads `enabled` + `layerCount` from this setting; SC-1 forward entry
points are the greyed drawer stubs. Without the `DinghyApp.kt` creation site, `BabystepPrefs` has no
backing DataStore — the blocker Codex caught.

Output: `DinghyApp.kt` (new babystep DataStore + ctor wiring) + `BabystepPrefs.kt` (new) + `AppContainer`
ctor param + intent helpers + Settings UI + 2 drawer stubs; ShellPresenceTest extended.
