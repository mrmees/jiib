|---|---|
| UI -> FileBrowserHolder | User selection and actions mutate holder state. |
| Holder -> FileBrowserClient | Holder requests reads/actions through a narrow facade. |
| FileBrowserClient -> Dispatcher/JsonRpcClient | Client bridges typed registry specs to the live session. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-07-01 | Tampering | Delete action | mitigate | Holder blocks delete while printing/paused and clears selected row only after successful delete. |
| T-07-02 | Spoofing | Print start pending | mitigate | Pending clears only on matching printer state, not command ack. |
| T-07-04 | Tampering | Client method shape | mitigate | Client uses registry specs and Plan 02 path helpers. |
| T-07-05 | Denial of Service | Stale session/pending action | mitigate | Container swaps client atomically; holder clears pending on incompatible state/session changes. |
</threat_model>
