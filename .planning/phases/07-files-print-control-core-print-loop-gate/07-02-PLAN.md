## Trust Boundaries

| Boundary | Description |
|---|---|
| Moonraker JSON -> File models | Untrusted server payloads become file rows and preview data. |
| File path helpers -> Commands | Parsed paths become start/delete command parameters in later plans. |
| Metadata -> Thumbnail URL | File metadata and filenames become HTTP thumbnail URLs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-07-01 | Tampering | Delete path helper | mitigate | Tests prove delete paths are root-prefixed and start paths are not. |
| T-07-02 | Spoofing | Preview data | mitigate | Preview fields are parsed from selected file metadata and nullable when absent; UI cannot invent success. |
| T-07-04 | Tampering | Path discipline | mitigate | Path forms are modeled separately and covered by fixtures. |
| T-07-05 | Denial of Service | Metadata and thumbnails | mitigate | Parser is null-safe; holder/UI plans fetch rich metadata only for selection. |
</threat_model>
