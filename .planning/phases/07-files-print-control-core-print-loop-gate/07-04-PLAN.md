| ConfirmGuard -> Holder action | Guard commitment invokes the actual destructive or print-start behavior. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|

| T-07-05 | Denial of Service | List scrolling and thumbnails | mitigate | RecyclerView field, compact rows, bounded thumbnail decode/cache behavior, selected-file metadata fetch, and graceful fallback visuals. |
</threat_model>
