CRITICAL Wave-0 scaffold contract (cross-wave compile rule): Gradle compiles the ENTIRE `testDebugUnitTest` source set BEFORE `--tests` filtering. A scaffold that makes a direct typed reference to a production symbol not built until a later wave (e.g. `MjpegStreamDecoder`, `WebcamProbe`, `SnapshotPoller`, `WebcamHolder`, `SpineHandle.webcams`) would fail to COMPILE the whole source set — breaking every targeted unit-test run in the intervening waves (e.g. 10-02's `--tests *WebcamListParseTest*` would fail at compile, not run). Therefore EVERY Wave-0 scaffold must COMPILE from day one and fail at RUNTIME instead: a body of `org.junit.Assert.fail("RED until plan 10-0N builds <Symbol>")` (or a reflection/string-based check) — genuinely RED (fails when run) yet keeps the whole test source set compiling. The plan that BUILDS each symbol then REPLACES the scaffold body with the real typed assertions against the now-existing symbol.
