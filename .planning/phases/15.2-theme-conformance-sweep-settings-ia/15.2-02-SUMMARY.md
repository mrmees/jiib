**Two floating dev cyclers (6-combo Style + S/M/L Size) that flip the whole live app's theme transiently via the override layer — axes runtime-independent (merge-onto-current) and rapid-tap-safe (atomic stepping) — the conformance accelerant for the rest of the sweep.**

## Accomplishments
- `DevThemeCyclerOverlay` — two small (>=64px) floating cycler widgets, every color via `LocalTokens.current` so the chrome themes WITH the app, STATIC (no looping animation, Adreno-320 motion LAW).
- Pure `nextStyleOverride`/`nextSizeOverride` steppers that step their axis through the 6 `{dark,light}x{Colorful,Simple,HighContrast}` combos / S/M/L and **merge onto the current override** so the two axes are truly independent at runtime (HIGH-4).
- Wired into `AppShell` as a `devCyclerEnabled`-gated overlay Box drawn above `when(dest)`, stepping atomically through `container.updateThemeOverride { next*Override(it) }` (MEDIUM); dismiss clears via `setThemeOverride(null)`.
- TEMP `devEnableFlow` default flipped to `true` (tagged `// TEMP(15.2-02)`, reverted in 15.2-04) so the cyclers appear in the RELEASE APK for the pre-About on-device walk (MEDIUM-3).
- On-device cycler-walk on flox + live printer **PASSED** — the whole app (incl. classic-Views surfaces) flips across all 6 styles, seed/accent preserved, S/M/L independent, restores cleanly on dismiss, static with no jank.
