> ⚠ AGP glob gotcha: `--tests 'works.mees.dinghy.theme.*'` may false-fail "No tests found" —
> list test classes explicitly if it does.

## Sampling Rate

- **After every task commit:** Run the quick command for the touched package.
- **After every plan wave:** Run the full unit suite.
- **Before `/gsd-verify-work`:** Full unit suite green AND the on-device eyeball gates (below) signed off by the owner.
- **Max feedback latency:** ~120 s (host JVM).

## Per-Task Verification Map

> The phase has two validation halves (RESEARCH § Validation Architecture):
> **(1) logic that is host-pure-testable** — the transient theme override resolver, the IA
> persistence/per-profile toggles, the Devices→Printers rename invariants; and
> **(2) the conformance sweep itself**, which is fundamentally an on-device visual judgment
> (the `fsSp` / button-intent / FFG / ≥64px dimensions cannot be asserted by a JVM test the way
> a colour-token equality can). Half (1) gets automated verify; half (2) gets the on-device
> eyeball gate + the AUDIT.md scorecard as the durable artifact of record.
