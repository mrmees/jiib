tuple/profile shape.

stored field, and `AppContainer.seedTheme`; the resolver hardcodes the 4-slot default at the
`Palette.generate` boundary; `Palette.generate(maxItems=...)` and `TemperatureScreen`'s `maxItems=8`
call are PRESERVED; every theme test that named `maxItems` is updated; the sourceset compiles.
