## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | JUnit4 host unit tests (`app/src/test`); Compose `@Preview` matrix for visual checks; on-device flox UAT for legibility |
| **Config file** | Gradle (`app/build.gradle.kts`) — no separate runner config |
| **Quick run command** | `cmd.exe /c "E:\Android\gw.bat :app:testDebugUnitTest --tests works.mees.dinghy.designsystem.icons.DinghyIconsTest --no-daemon"` |
| **Full suite command** | `cmd.exe /c "E:\Android\gw.bat :app:testDebugUnitTest --no-daemon"` |
| **Estimated runtime** | ~10s quick (single class) · ~60–120s full host suite |

Builds run Windows-side via `E:\Android\gw.bat` — `./gradlew` does not run from WSL. Pipe CR
progress bars through `tr -d '\r'`; the process exit code is authoritative. Guard hung Gradle runs
with `timeout` + `taskkill /F /T` (see `dinghy-display-gradle-hang-interop` memory).

---

## Sampling Rate

- **After every task commit:** Run the quick command (`DinghyIconsTest`) — catches the
  `LauncherSpool` Ligature→Drawable registry-drift breakage immediately.
- **After every plan wave:** Run the full suite command.
- **Before `/gsd-verify-work`:** Full host suite must be green AND the on-device flox visual UAT
  must pass (band reads at launcher/drawer size; empty-spool fallback; dark + light + custom legibility).
- **Max feedback latency:** ~120s (full host suite).
