## Pattern Assignments

### `app/src/main/res/drawable/spool.xml` (NEW — config / vector asset)

**Analog:** `app/src/main/res/drawable/nozzle.xml` (also `heat_bed.xml`)

**Authoring convention to copy verbatim:**
- 96×96 viewBox, `android:width/height="96dp"`, `viewportWidth/Height="96"`.
- Every visible region is a `<path>` with `android:strokeColor="#FFFFFFFF"`, `strokeWidth="4"`, `strokeLineCap="round"`, `strokeLineJoin="round"`. White stroke → recolored at runtime via Compose `Icon(tint = …)` (THEME-01).
- Leading XML comment documenting the SVG→VectorDrawable conversion (polygons/lines rewritten as `M…L…Z` path data — VectorDrawable has no polygon/line primitive).

**Header comment template** (from `nozzle.xml:1-6`):
```xml
<!--
  Nozzle / extruder hotend glyph. Converted from img/nozzle.svg (viewBox 0 0 96 96): the SVG
  <polygon> elements are rewritten as closed M…L…Z path data ... Strokes are drawn white and
  recolored at runtime via Compose Icon(tint = trace color) so the glyph honors the semantic
  token system (THEME-01).
-->
```

**Vector skeleton** (from `nozzle.xml:7-17`):
```xml
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="96dp"
    android:height="96dp"
    android:viewportWidth="96"
    android:viewportHeight="96">
    <path
        android:pathData="M61,66h14c1.7,0,3,1.3,3,3..."
        android:strokeColor="#FFFFFFFF"
        android:strokeWidth="4"
        android:strokeLineCap="round"
        android:strokeLineJoin="round" />
</vector>
```

**PHASE-CRITICAL DEVIATION (D-01/D-04, Research anti-pattern):**
- This vector draws the **body/flanges ONLY**. It must **EXCLUDE** the wound-filament band region entirely — the band is drawn exclusively by `SpoolGlyph`'s Canvas overlay.
- **Do NOT** bake a `<gradient>` into the XML. Filament color is dynamic runtime data; a static `<gradient>` is explicitly forbidden (D-04).
- Double-drawing the band area (token-tinted vector band peeking through the Canvas band) causes a visible seam — author the silhouette so the band rectangle is empty negative space the Canvas owns.
- Band geometry (left/right/top/bottom edges) must be authored as **fixed fractions of the 96-unit box** so `SpoolGlyph`'s Canvas can reproduce the identical rectangle (see Pitfall 3 in RESEARCH).

**The recommended `SpoolGlyph` shape (RESEARCH Option C, lines 333-363):**
```kotlin
@Composable
fun SpoolGlyph(
    swatches: List<Color>,     // 0 = empty spool (D-03), 1 = solid (D-08), 2+ = two-stop gradient (D-04, take 2)
    bodyTint: Color,           // neutral role token (D-02)
    keyline: Color,            // neutral role token (D-05)
    sizeDp: Dp,
    modifier: Modifier = Modifier,
    contentDescription: String? = null,
) {
    Box(modifier.size(sizeDp)) {                            // ONE coordinate frame for both layers (Pitfall 3)
        Icon(painterResource(R.drawable.spool), contentDescription, Modifier.fillMaxSize(), tint = bodyTint)
        Canvas(Modifier.fillMaxSize()) {
            if (swatches.isEmpty()) return@Canvas           // D-03 empty spool — band OMITTED entirely
            val bandPath = spoolBandPath(size)              // fractions of the box, matches the vector body's gap
            val brush = when (swatches.size) {
                1 -> SolidColor(swatches[0])                // D-08 single color
                else -> Brush.linearGradient(               // D-04 two-stop; EXPLICIT stops to band bounds (Pitfall 4)
                    0f to swatches[0], 1f to swatches[1],
                    start = Offset(bandLeft(size), 0f), end = Offset(bandRight(size), 0f),
                )
            }
            drawPath(bandPath, brush)
            drawPath(bandPath, keyline, style = Stroke(width = keylineWidth(size)))   // D-05 neutral keyline
        }
    }
}
```

**Adreno-320 discipline (from `ColorWheel.kt:32-43, 68, 182-188`):**
- The band is **static** (root CLAUDE.md "NO continuous animation"). Build the `Brush.linearGradient` inside the `DrawScope` — it is cheap and the glyph is small/static with ONE instance per surface. Only `remember`-key it on the swatch list if the same glyph is drawn many times in a list (not the case here).
- ColorWheel caches its sweep gradient via `androidx.compose.runtime.remember { … }` (`ColorWheel.kt:184-188`) — use the same pattern only if profiling shows allocation cost; CONTEXT/RESEARCH say allocation is negligible at these sizes.

**Imports pattern** (from `ColorWheel.kt:1-25`): `androidx.compose.foundation.Canvas`, `androidx.compose.ui.geometry.Offset`, `androidx.compose.ui.graphics.Brush`, `androidx.compose.ui.graphics.Color`, `androidx.compose.ui.graphics.SolidColor`, `androidx.compose.ui.graphics.drawscope.Stroke`, `works.mees.dinghy.theme.compose.LocalTokens`.

**Pitfalls (RESEARCH):** explicit gradient `start`/`end` to the band bounds (P4); body/band coordinate frames pinned to the same `Box(Modifier.size(sizeDp))` (P3); empty-spool OMITS the band, never draws a dead-token placeholder (P5).

## Shared Patterns

### Token-routed chrome + literal-data-color carve-out (THEME-01)
**Source:** `ColorWheel.kt:45-49, 128-147` (literal hue + token outline); THEMING.md:317-336.
**Apply to:** `SpoolGlyph` (band = literal filament color; body + keyline = neutral tokens), the docs edit.
The band is the spool analogue of ColorWheel's handle dot: literal data-color fill, token-color keyline stroke.

### `fsSp(baseSp, t.fs)` sizing — never hardcode
**Source:** used app-wide; e.g. `AppDrawer.kt:261` (`fsSp(40f, t.fs)`), `PrintStatusScreen.kt:1121` (`fsSp(40f, t.fs).dp`), `SpoolScreen.kt:326` (`fsSp(64f, t.fs).dp`).
**Apply to:** every `SpoolGlyph` call site. Launcher/drawer/shortcut = `fsSp(40f, t.fs)`; SpoolScreen empty/detail = `fsSp(64f, t.fs)`. Memory: dinghy-font-sizes-too-small.

### Stateless-screen color threading
**Source:** `AppDrawer.kt` `spoolEnabled`/`webcamEnabled` params (`:78-86`, threaded by the shell).
**Apply to:** thread `spoolSwatches: List<Color>` into `AppDrawer` and down `PrintStatusScreen`'s `LauncherTile`/`ShortcutRow` — resolved once from the existing `spoolDetail` state, never re-fetched.

### Static rendering only (Adreno-320 floor)
**Source:** root CLAUDE.md "NO continuous animation"; `ColorWheel.kt:141` ("static edge-glow ring — no looping animation").
**Apply to:** `SpoolGlyph` — the band/keyline draw once per recomposition, only when resolved swatches change. No animation.

### Hex → Color (do not duplicate)
**Source:** `SpoolScreen.parseNormalizedHex` (`:502-505`) + `SpoolmanModels.normalizeColorHex` (`:147-152`).
**Apply to:** promote `parseNormalizedHex` to `internal` top-level; `SpoolGlyph`, `SpoolScreen`, and `PrintStatusScreen` all call the one promoted helper.
