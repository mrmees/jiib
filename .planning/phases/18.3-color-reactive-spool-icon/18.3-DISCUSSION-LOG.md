## Glyph design & what tints

### What tints
| Option | Description | Selected |
|--------|-------------|----------|
| Whole glyph | Entire icon renders in the filament color (single-path tint) | |
| Filament-only | Two-region vector: filament band takes the color, flanges/body stay neutral token | ✓ |

### Multi-color handling
| Option | Description | Selected |
|--------|-------------|----------|
| First/dominant swatch | Single color from the first swatch (most legible at small size) | |

**User's choice:** Filament-only tint + two-stop gradient (the richer illustration on both axes).
**Notes:** Implies a multi-region vector and a RUNTIME gradient brush (not a baked VectorDrawable
`<gradient>`) — flagged in CONTEXT D-04 as the key research question. Silhouette settled as side-view
(band between flanges) by the preview the user selected.

## Legibility + fallback

| Option | Description | Selected |
|--------|-------------|----------|
| True color + neutral keyline | Exact hex + thin token outline so the band always reads | ✓ |
| WCAG clamp (reuse brandTint) | Nudge color toward 3:1 contrast (distorts true color) | |
| Neutral backing chip | Neutral surface behind the band | |

**User's choice:** True color + neutral keyline.
**Notes:** Honors the "filament color is DATA, not chrome" carve-out — legibility via framing, never by
distorting the real color. `brandTint` clamp explicitly rejected for the band. No-color fallback already
settled as the empty spool (from the Surfaces discussion).
