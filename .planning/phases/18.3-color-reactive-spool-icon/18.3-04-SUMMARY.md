## ⚠ Mid-flight correction — the spool art (IMPORTANT)
This phase originally hand-authored a FAKE side-view spool (flanges + a rectangular "band") and built the whole renderer around invented band fractions — **ignoring the owner's real front-view source art `img/spool.svg`** (present in the repo since 2026-06-05). The owner caught it at the first UAT. Corrected before sign-off:
- **`fix(18.3)` `00907e8`** — `spool.xml` reworked to the real art: the spool BODY DISC (3 windows as `evenOdd` holes). `SpoolGlyph` reworked to draw the wound-filament **SPIRAL** behind the disc (showing through the windows), tinted by the live color — solid for one, two-stop gradient along the coil for multi-color (D-04), omitted when empty (D-03), neutral keyline outlining the coil (D-05/SC5). The public `SpoolGlyph(...)` API was preserved, so Tasks 1-3's wiring needed no change. `BandRender`/`bandRenderFor` → `SpiralRender`/`spiralRenderFor`.
- **`docs(18.3)` `b667f44`** — THEME-01 carve-out reworded band → spiral in `THEMING.md` + `ui_design/CLAUDE.md`.
- **`docs(ui)` `7b3beff`** — recorded the owner's hard law: **never create an icon or choose a glyph independently — ASK** (project icon doctrine + memory).

The earlier 18.3-01 / 18.3-02 / 18.3-03 SUMMARYs describe the original invented-spool approach and carry a correction note pointing here.
