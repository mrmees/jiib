# Phase 8 — UI Design Contract

> Visual and interaction contract for the Macros & Console functional-core-complete gate. Generated by gsd-ui-researcher, verified by gsd-ui-checker. Native Android (Compose + classic Views hybrid, ADR 0001) — the canonical design law in `docs/ui_design/` supersedes any generic template defaults. **No hi-fi mockup exists for these screens (08-CONTEXT D-11): they are designed fresh WITHIN the Focus/Field/Gutter grammar, not improvised.**

## Design System

| Property | Value |
|----------|-------|
| Tool | Native Android hybrid Dinghy design system; no shadcn (not a React/Next/Vite project — shadcn gate not applicable) |
| Preset | not applicable |
| Component library | Existing primitives: `ScreenScaffold` (Focus/Field/Gutter), `OutlinedControl` (intent-colored 2px-outline control), `ConfirmGuard`, `SeverityToast` (PRIM-04), `NumpadPage`, `ScrubberPage`, `MaterialSymbol`. Console scrollback reuses the proven RecyclerView-in-`AndroidView` pattern from `ui/files/FileListView.kt`, backed by the new object-typed `state/ConsoleScrollback.kt` (NOT `render/RingBuffer.kt`, which is FloatArray-only and cannot hold ConsoleLine — S1) |

## Spacing Scale

Production 4/8/16/24/32/64 grid. All region/cell sizing is ratio-only (`weight`, `%`, `aspectRatio`, container-relative) per LAYOUT.md NON-NEGOTIABLE 3 — the px values below are only for control padding, gaps, corner radius, the touch floor, and the `--fs` text step.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon-to-label gaps, console line inner micro-gaps, severity-dot offset |
| sm | 8dp | Console line vertical rhythm, list row gaps, chip icon gap, filter-toggle inline spacing |
| md | 16dp | Default control/region padding, control corner radius (`--r-ctrl` 16px), macro-row padding |
| lg | 24dp | Screen/region padding, execution-popup field padding |
| xl | 32dp | Focus-to-content breathing room where space allows |
| 3xl | 64dp | Minimum touch-target height AND gutter button height (≥64dp, per UI-02) |

Exceptions: console line height is content-driven (text + `--fs`), not a fixed grid step — it must remain dense enough to show meaningful scrollback. Card radius `--r-card` 22px for the execution popup surface. No hardcoded region sizes.

## Typography

All sizes are base `sp` multiplied by `ThemeTokens.fs` (`S≈1.0`, `M≈1.15` default, `L≈1.32`). Four sizes, exactly two weights. Sizes track the canonical `hifi.css` type ramp (14px chip/label tier, 16px body, 18px `.ctl` control, ~28px display title).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label / metadata / filter-toggle / console line / param value | 14sp * fs | 400 | 1.3 |
| Body / macro name | 16sp * fs | 400 | 1.35 |
| Control / gutter / list emphasis | 18sp * fs | 600 | 1.2 |
| Display / popup title | 28sp * fs | 600 | 1.15 |

Console lines and parameter values use **Geist Mono** (tabular); labels, metadata, and filter-toggle text use Geist — both share the 14sp step. Body/macro names use Geist. Text fills its box at all three `--fs` settings (LAYOUT "panel text fills the box"); a single overflowing console line may marquee on overflow — never lock-width a console line to a narrower inner ruler.

## Color

Token-first; hex values are the checked-in dark-theme sRGB fallbacks from `BakedTokens.kt`. Components reference role tokens, never raw color (THEME-01).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--bg` `#0C1015`; `--surface` `#171C23` | Full-screen background, screen body, console scrollback well, list backgrounds |
| Secondary (30%) | `--bg-2` `#12161C`; `--surface-2` `#20262E`; `--outline` `#4B535E` | Console line rows, macro list rows, checkboxes/toggles, neutral controls, filter chips, inactive tracks |
| Accent (10%) | `--accent` `#4C94EC`; `--accent-2` `#70ADFB`; `--accent-line` `#8C4C94EC` | Selected/bookmarked macro affordance, active filter-toggle edge, the **Execute** gutter action (ordinary physical command), pending-dispatch indicator |
| Caution | `--heat` `#F3A958` | Console **warning** lines (`//` echo/notice); the **Numpad/Scrubber-set** affordance for numeric params if it commits motion/heat |
| Positive | `--go` `#5AC576` | Console **normal/success**-tier lines (plain ok); the **Back**/**Cancel** popup dismiss (backing out changes nothing → green, NOT red) |
| Destructive | `--stop` `#F4514F` | Console **error** lines (`!!`); reserved — no destructive ACTION introduced this phase (read-only console; macro run is not classified destructive) |

Accent reserved for: bookmarked/selected-macro state, the active state of a filter toggle, the Execute action, and bounded pending-dispatch indicators. Accent is NOT a blanket interactive color.

**Console severity coloring (CONS-02 / D-02), color + the existing severity vocabulary — never color alone, always with the line text:**
- `!!`-prefixed → error tier → `--stop` (red) text/marker
- `//`-prefixed → echo/warning tier → `--heat` (amber) text/marker
- plain → normal tier → `--text` (`#F0F2F4`) default, or `--go` for explicit `ok`/success lines

**Execute/Cancel intent (resolves D-08 discretion against THEMING safety doctrine):** Execute = `--accent` (blue, an ordinary physical command — the param-entry popup IS the deliberate action gate, D-08, so it does not warrant amber-peril chrome by default). Cancel/dismiss = `--go` (green safe-dismiss). A macro KNOWN to drive heat/motion may be promoted to `--heat` (amber) Execute per the override clause — planner's call per macro where statically detectable, default accent.

## Visual And Interaction Contract

### Console Screen (read-only — D-01)

- Built on `ScreenScaffold`. **Field-only screen**: the Field IS the scrollback list; Focus is omitted (the freed height goes to scrollback — "fill the usable space").
- Console scrollback is the **3rd Views-in-Compose scroll surface** (D-05). Apply the Files scroll lesson VERBATIM: real RecyclerView in `AndroidView` over-measures and composites over neighbors unless pinned — `BoxWithConstraints` → `.height(maxHeight)` **+ `Modifier.clipToBounds()`**. Reuse the `ui/files/FileListView.kt` pattern; back the bounded scrollback with the object-typed `state/ConsoleScrollback.kt` (an ArrayDeque-backed `ConsoleLine` ring) — NOT `render/RingBuffer.kt`, which is FloatArray-only (S1).
- **The global swipe-up App Drawer gesture MUST be suppressed on this screen** (scroll-Field law) — the full-canvas vertical-drag detector fights the list scroll. Keep an explicit **Back** exit in the Gutter (green, per safety doctrine — backing out changes nothing).
- Each line: severity marker/color + the raw response text in Geist Mono, left-aligned, full cell width (panel-text-fills-the-box law). Timestamp display per line is **planner's discretion** (D-02 discretion) — if shown, render in `--text-3` faint, leading, monospace.
- **Auto-scroll stick-to-bottom** unless the user has scrolled up (then hold position; new lines accrue below). Sensible scrollback bound ~1000 lines (planner may tune, D-02).
- **Opt-in noise filters (D-03, default OFF)** surfaced as toggle controls in the Gutter (or a compact filter row at the top of the Field if the planner prefers — must not steal scrollback height meaningfully): **Hide temperatures**, **Hide Timelapse**, **Hide prompt commands**. Mirror the Mainsail fork rule set (canonical refs). Active toggle = `--accent` edge; inactive = neutral `--outline`.
- **Architecture (D-04, LOAD-BEARING):** the display filter is a VIEW-layer concern ONLY. The raw `notify_gcode_response` + `server.gcode_store` stream stays upstream of / independent of the console display filter — backfill and the future Phase-12 prompt engine must never be starved by what the console hides.
- Backfill from `server.gcode_store` on connect AND reconnect (D-02) — never silently drop lines that arrived while disconnected.
- No keyboard, no text input field, no send button (D-01 — read-only).

### Macros — three screens (D-06 / D-07 / D-08)

**1. Bookmarked launcher (the drawer "Macros" tile opens THIS — D-07):**
- The everyday launcher. Field shows ONLY user-selected (bookmarked) macros as a grid/list of tappable `OutlinedControl` tiles; tapping a macro opens its Execution popup.
- A Gutter control reaches the System list to manage selection (e.g. "Manage" → System list); Gutter also carries **Back** (green).
- Empty (no bookmarks yet): show the empty-state copy and a clear route to the System list.

**2. System macro list (manage visibility — D-06 / MACRO-03):**
- Field is a scrollable list of ALL discovered macros (from `printer.objects.list` / `configfile`), each row a name + a check/select control choosing whether it surfaces in the Bookmarked launcher.
- **Underscore-prefixed macros hidden by default** (real printers carry 96/60 macros, mostly internal helpers); a toggle reveals them.
- If this list is finger-scrollable, it is also a scroll-Field → **suppress the swipe-up drawer** here too and keep an explicit Gutter **Back**.
- Selected/bookmarked state = `--accent` checkmark/outline.

**3. Execution popup (params + run — D-08):**
- Full-screen overlay surface (`--r-card` 22px), gutter-less in the ConfirmGuard sense — **the popup IS the deliberate action gate (D-08); do NOT layer a separate ConfirmGuard on top.**
- Shows: the macro name (Geist Mono, prominent) + **auto-detected parameter fields** (one per detected param — D-09, parsed from the macro gcode body for `params.X` + `|default(...)`), with the default pre-filled where parsed.
- Gutter: **Execute** (`--accent`) · **Cancel** (`--go`, safe dismiss).
- **Parameter entry (D-10 — resolves the PRIM-02 keyboard triage):**
  - Numeric params → existing `NumpadPage` (keyboard-free numeric entry; consistent with all other printer-control numeric input).
  - String params → the on-screen system keyboard. **This popup is the ONE place the alpha keyboard is allowed inside printer controls** — confined here, never elsewhere in the control surfaces.
- A param with a parsed `|default(...)` and no user edit sends the default. Missed-edge-case params (D-09 is a heuristic) degrade gracefully — never block Execute on a param the parser couldn't classify.

### Drawer wiring

- Wire the currently-greyed "Macros" tile (`ui/shell/AppDrawer.kt`, `symbol = "code"`, `dest = null`) to open the **Bookmarked launcher**.
- A **Console** tile is likely added alongside (D-11 discretion / planner's call) — new tile vs. shared structure decided in planning. If added, pick a Material Symbol NOT already used on the drawer (no repeated glyph — CLAUDE.md icon law).

### States

- Console empty (no lines yet / fresh connect before backfill): show empty-state copy; once `gcode_store` backfills, lines populate.
- Console disconnected / backfill failed: keep the scrollback stable, surface the connection state contextually (color on an existing element, no global chrome) — do not blank the history.
- Macros unavailable (no `gcode_macro` objects on this printer — capability-gated via `Capabilities`/`DeriveCapabilities`): the Macros feature degrades — show the no-macros copy; do not show dead tiles.
- Macro dispatch pending: show the bounded in-flight/disabled state on the Execute control (PRIM-05 dispatch primitive) until the command resolves; a `!!` rejection surfaces as a `SeverityToast` error AND in the console history. Do not treat command-ack as success-of-effect.
- Param-parse miss: render whatever fields were detected; Execute stays enabled.

### Performance And Accessibility (Adreno-320 floor)

- Console list is RecyclerView + `ConsoleScrollback` (the object-typed ArrayDeque-backed ring — NOT the FloatArray `RingBuffer`, S1) through the Compose shell; lines append without per-line recomposition of the tree. No looping/continuous animation (static glow only — Adreno-320 budget).
- No animated list insertion, no shimmer, no breathing.
- Every control has an accessible label/content description; gutter controls keep icon+label where space allows.
- Action glyphs never repeat on one surface (filter toggles, Execute/Cancel, Back must use distinct glyphs or ≤3-char text labels).
- Touch targets ≥64dp tall.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (macro) | `Execute` |
| Popup dismiss | `Cancel` |
| Console exit | `Back` |
| Manage-selection control | `Manage macros` |
| Console empty state heading | `Console is quiet` |
| Console empty state body | `Printer responses appear here. Run a command or macro and the reply shows up live.` |
| Console backfill-failed state | `History unavailable. Check the printer connection — live responses will still appear.` |
| Bookmarked-empty heading | `No macros pinned` |
| Bookmarked-empty body | `Pick the macros you use most in Manage macros, and they'll launch from here.` |
| System-list intro (hidden-helpers note) | `Underscore-prefixed helper macros are hidden. Show hidden to reveal them.` |
| Macros-unavailable state | `This printer reports no gcode macros. Add gcode_macro entries in your config to use this screen.` |
| Filter toggles | `Hide temperatures` · `Hide Timelapse` · `Hide prompt commands` |
| Show-hidden toggle | `Show hidden` |
| Execution popup title | `Run {MACRO_NAME}` |
| Macro dispatch pending | `Running {MACRO_NAME}... waiting for the printer.` |
| Macro rejected (severity toast) | `{MACRO_NAME} was rejected: {printer message}` |

No destructive confirmation row this phase — the console is read-only and macro execution is gated by the popup itself (D-08), not classified as destructive. (Reserved `--stop` is for error-tier console lines only.)
