<objective>
Build the per-type immediate-dispatch detail pages: a shared scrubber detail (fan %, heater °C, servo °,
output_pin-pwm %, pwm_tool %), the LED page (hue ColorWheel + brightness scrubber + explicit Off, D-12),
and the output_pin page that branches digital→toggle / pwm→scrubber (the toggle is the one new small UI
piece). Every page dispatches immediately on settle (no Apply, no ConfirmGuard), shows failures as a
toast, and scopes busy to the page.

Purpose: SC-2 (keyboard-free set, confirmed by state flip) + SC-3 (read-only degrades). The staging grammar
is strict: immediate dispatch, NO Apply flow, NO ConfirmGuard even for risky pins/PWM, Off dispatches
immediately, toast feedback, stay-on-page on failure. ScrubberPage has an Apply/Cancel contract that
conflicts — wire dispatch-on-settle (the ColorWheel onSettle cadence) instead. ColorWheel is hue-only, so
the LED page pairs it with a brightness scrubber + the 19-03 hsvToRgb helper (fixed saturation v1).
Output: the detail pages + the new toggle control + a detail preview matrix.
</objective>
