<objective>
Wire the Outputs feature into the shell: add `Dest.Outputs`, flip the pre-stubbed greyed `Output`
drawer placeholder to a LIVE runtime-gated tile that is HIDDEN entirely when zero outputs (D-10) via a
pure `visibleDrawerTiles(...)` helper, uses the `output` icon (D-07, sourced from the `DinghyIcons`
token so it can't drift), assemble `OutputsHolder` and host `Dest.Outputs` as a list↔detail local
back-stack that resets the selected output when its descriptor disappears, and suppress the swipe-up
drawer on the Outputs screen. Add a host-test for the D-10 hide gate.

Purpose: SC-1 ("see every output, and nothing it doesn't") closes here at the entry point — the tile
must HIDE when empty (D-10 diverges from the existing Spool/Webcam GREY pattern) and route to Outputs
when present (D-11). The list↔detail back-stack mirrors the Calibration dest host (a local hub↔routine
stack, not five top-level Dests). Three review gates close here: (1) the drawer renders ligature strings
today, but 19-01 created `DinghyIcons.OutputSection` (= `output`) — source the tile symbol FROM that token
so the icon-law-locked glyph can't drift from a hand-typed string; (2) `outputsPresent` must be scoped to
the active spine/store so a disconnect or printer-switch idles it (no stale process state showing a tile
for a printer that's gone); (3) extract the hide/show decision into a pure `visibleDrawerTiles(...)` helper
with a host test, and RESET the selected output when its descriptor disappears (a removed/renamed output
must not strand the user on a dead detail page).
Output: the Dest constant, the token-sourced gated tile + pure helper, the shell host wiring with
selection-reset, drawer suppression, and the gate test.
