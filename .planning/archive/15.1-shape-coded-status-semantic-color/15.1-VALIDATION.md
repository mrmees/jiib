| **Full suite command** | `/mnt/c/Windows/System32/cmd.exe /c "E:\Android\gw.bat :app:testDebugUnitTest --no-daemon"` (host); `:app:connectedDebugAndroidTest` on flox for instrumented |

---

## Sampling Rate

- **After every task commit:** Run the relevant host unit test (`testDebugUnitTest --tests '<Class>'`)
- **After every plan wave:** Run the full host unit suite (`:app:testDebugUnitTest`)
- **Before `/gsd-verify-work`:** Full host suite green **AND** on-device UAT of the visual decisions (D-01 silhouettes incl. grayscale, D-06 accent-leads, D-11 ramp)
- **Max feedback latency:** ~120 s (host suite)

> History: green unit suites have repeatedly missed runtime/visual reality on this project (multiple mock-vs-reality strikes). The on-device eyeball is **mandatory**, not optional, for every visual decision.
